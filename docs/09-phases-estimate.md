# Phases and estimate

Do not start Phase 1 code until `STATUS.md` is approved **and** must-ask items in `08` have answers (or explicit “use defaults”).

## Phase 0 — this folder (done)

Specs, Cursor rules, stack, questions.

## Phase 1 — MVP (recommended first invoice)

- Agent: punches, clicks, key counts, window titles, screenshots, offline sync
- API + Postgres
- Admin: live board + day view + attendance table + PDF/CSV
- Device enroll, 12 users, 60-day screenshot retention default
- **Duration:** 3–4 weeks one senior (or 5–6 if part-time)
- **Quote band (PK, 2026):** PKR **250,000–400,000** once scope is locked  
  (This is above a TimesheetV2 clone because live + screenshots + multi-user + anti-tamper are extra.)

## Phase 2

- Project costing, Google Sheet auto-sync, employee self-service, screenshot blur, idle detection, overtime rules, 50+ users hardening

## What not to quote as “one blob”

Do not sell “full EMS + payroll + mobile + video” as one price. That is a different product.
