# Sign-out vs manager access (locked)

## Employee PC after Sign Out

- **Tracking band** = us PC pe ab naya screenshot / click / key count **nahi** chalta.
- Ye spyware nahi: kaam khatam → monitor band.

## Manager / CEO / employer

- Sign Out ke **baad bhi** manager website se **purana record** dekh sakta hai:
  - us din / pehle dinon ki attendance
  - screenshots jo pehle capture ho chuki thin
  - activity, PDF, monthly reports
- “Tracking band” ≠ “data delete” ≠ “manager blind”.
- Data **office server** pe rehta hai jab tak retention allow kare (shots ~30 days; attendance longer).

## Simple line for client

> Employee Sign Out kare to uske PC pe recording ruk jati hai. Aap manager login se pehle wala sara data, reports, screenshots kabhi bhi dekh sakte ho.
