# External clients (your customer's customers) — recommendation

## Should Harbour / Summit see the Design Queue board?

**No — not the internal board.** Top AEC / studio tools (FrameCAD shops, Monday internal ops, Procore client view) split:

| Audience | What they see |
|---|---|
| **CFS Admin / CEO** | Full queue + $ + screenshots |
| **CFS employees** | Own jobs / own day — no $ |
| **External client (Willie, Harbour…)** | Optional later: **client portal** — only *their* project status (Intake → … → Run Files), due date, “waiting on payment” soft message — **never** other clients, never staff screenshots, never full finance sheet |

## Payment notifications?

Market pattern:
1. **In-app** for CFS finance (already: delayed days, Paid status) — do this first.
2. **Email/WhatsApp to external client** — only after you approve copy + consent (not auto-blast).
3. Never put bank scraping / card numbers in this app.

## v1 (now)

Internal office OS only. External portal = Phase later if client asks.

Do **not** share admin login or Design Queue with outside clients.
