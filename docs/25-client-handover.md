# Client handover (professional)

**Updated 31 Aug 2026:** Live web is **https://ems.cfsdesigners.com**. Agent = `CFS-Agent-Install.zip` (no Python). Client voice that night: enroll staff **this week**; video of PC setup; HR/expenses later. See `docs/37-client-handover-ur-en.md` and `docs/42-client-voice-2026-08-30-plan.md`.

## What you deliver

1. **Windows agent installer** (or setup ZIP) for each employee PC  
2. **Office server** package: API + DB + `data/` folder + `.env`  
3. **Manager web** (built static files or URL on LAN)  
4. **Admin credentials** + how to enroll PCs  
5. **1-page runbook** (start/stop/backup)  
6. **Staff notice** text (monitoring disclosed)  
7. **Training**: 30 min manager + 10 min per employee  

## Handover day agenda

| Step | Who | What |
|---|---|---|
| 1 | You | Install server on office PC, seed admin, verify health |
| 2 | You | Open manager web on owner laptop; login |
| 3 | You + owner | Enroll 1–2 pilot PCs; Sign In; show LIVE + screenshot |
| 4 | You | Show day PDF + CSV export |
| 5 | Owner | Confirm theme/flow OK |
| 6 | You | Backup demo; document passwords in sealed note |
| 7 | Both | Sign acceptance: Phase 1 scope complete; Phase 2 list separate |

## Acceptance checklist (client signs)

- [ ] Manager can login  
- [ ] Employee Sign In / Break / Sign Out works  
- [ ] Live board updates  
- [ ] Screenshots appear for signed-in time  
- [ ] Daily PDF readable  
- [ ] Attendance CSV downloads  
- [ ] After Sign Out, PC stops new tracking; history still visible  
- [ ] Training done
