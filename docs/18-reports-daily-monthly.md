# Reports

## Daily (MUST)

- Per employee: hours, breaks, clicks, key counts, idle minutes, 30‑min graph, top windows, screenshot index
- **Sessions table** if multiple Sign In/Out same day + net total
- Manager: team attendance table (sheet-like columns)
- PDF must be **readable** (structure in `docs/20-idle-sessions-pdf.md`) — not an unreadable raw dump

## Monthly (MUST)

- Per employee monthly compile:
  - days present / late / short day
  - total net hours, total break hours
  - average daily clicks / activity trend
  - top apps/windows (Work vs Other)
  - screenshot count (not every image in one PDF — summary + link to gallery)
- Team monthly summary for CEO
- Export: PDF + CSV

Generated on server (background job), not on employee PC.
