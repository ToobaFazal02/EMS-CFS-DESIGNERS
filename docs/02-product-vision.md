# Product vision

**CFS Designers** — one office platform for the CFS/LGS detailing company:

1. **Workforce** — trusted punches, activity, screenshots, live board, day/monthly reports (replaces Google Sheet times + TimesheetV2 PDF)
2. **Projects** — Design Queue Kanban + Project Details fields (replaces CFS PROJECTS sheet)
3. **Payments** — client invoice / follow-up pipeline with payment-before-delivery gates (replaces Payments Tracking sheet)

**UI name (client locked):** CFS Designers — **not** “EMS CFS”.  
Domain: remote CFS/LGS Estimation / Detailing / Engineering workstations — not civil site attendance.
