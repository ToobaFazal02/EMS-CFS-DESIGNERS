# Product vision

**CFS Designers** — one office platform for the CFS/LGS detailing company:

1. **Workforce** — trusted punches, activity, screenshots, live board, day/monthly reports (replaces Google Sheet times + TimesheetV2 PDF). **Pilot now (30 Aug voice).**
2. **Projects** — Design Queue Kanban + Project Details (replaces CFS PROJECTS sheet). **Built; client will use after employees are live.**
3. **Payments** — client invoice / follow-up pipeline with payment-before-delivery gates (replaces Payments Tracking sheet). **Admin only. Built; same sequencing.**
4. **Office expenses (later)** — HR sheet for chai/bills/electricity/gas/solar/parties. Month-end money in vs money out. **Not invoices.**

**UI name (client locked):** CFS Designers — **not** “EMS CFS”.  
**Live:** https://ems.cfsdesigners.com  
**Roles (30 Aug):** Admin = invoices; HR = attendance + projects + expenses (no invoices); Employee = own hours/projects; Agent = four buttons after one enroll.  
Domain: remote CFS/LGS Estimation / Detailing / Engineering workstations — not civil site attendance.
