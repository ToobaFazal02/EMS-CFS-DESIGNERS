CFS Designers Agent - install on your PC
========================================

You do NOT need Python or any extra software.

IMPORTANT
---------
Do NOT open INSTALL-AGENT.bat from inside WinRAR / 7-Zip.
Always EXTRACT the zip to a real folder first.

1. Right-click  CFS-Agent-Install.zip  →  Extract All...
   Good place:  C:\CFS-Designers-Agent
   (Extract the whole zip - you should see CFS-Designers-Agent.exe)

2. Open that extracted folder. Double-click  INSTALL-AGENT.bat

3. If Windows says "Windows protected your PC":
   click More info, then Run anyway.

4. When it asks "Start agent?" press Y

5. The Agent window opens.
   Paste the enroll code your manager sent you.
   Click  Enroll this PC

6. When you start work, click  Sign In  (green).
   When you finish, click  Sign Out  (red).
   Break In / Break Out if you take a break.

7. To hide the window, click Minimize.
   The CFS icon stays in the tray (near the clock).
   Click that icon to open the Agent again.

8. To close the Agent, click the X, then Quit (or Cancel to stay).

Re-enroll (new PC, or "Invalid device token")
---------------------------------------------
- Ask your manager for a NEW enroll code (Employees → Re-enroll).
- In the Agent, click  Re-enroll  (or clear and enroll again).
- Paste the new code → Enroll this PC → Sign In.

Software updates
----------------
- When a newer Agent is released, the app may show an Update available banner.
- Click Download Update, get the new zip from the office Downloads page,
  extract, and run INSTALL-AGENT.bat again (same folder is fine).
- You do not need to uninstall first. Keep your enroll unless the manager
  sent a new code.

Idle / screenshots
------------------
- If you do not move mouse or keyboard for about 30 seconds, status becomes Idle.
- Screenshots cover all monitors attached to this PC (1, 2, or more).

Do not delete or move this folder after install.
The Agent starts automatically when Windows starts.

Need a new enroll code? Ask the office. Do not share your code.
